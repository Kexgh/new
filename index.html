Welcome to a small Linux terminal styled CTF side project. Explore the filesystem, find flags, and submit them for the leaderboard.

  • help lists the main commands.
  • register <name> creates your player account.
  • login <name> signs you back in later.
  • submit FLAG{...} checks a flag and adds points.
  • leaderboard shows the current top users.

Password note: accounts use Firebase Auth. Your password is sent over HTTPS, stored by Firebase as a hashed credential, and this site does not save it locally or show me the plaintext.

Type tutorial any time to reopen this screen.
